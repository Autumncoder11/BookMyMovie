# Movie Booking Chatbot
A chatbot for booking movie tickets using Gradio, Transformers, SQLite, and LangChain.

## Setup
1. Install Python 3.8+.
2. Create a virtual environment: `python -m venv venv`
3. Activate: `source venv/bin/activate` (Linux/Mac) or `venv\Scripts\activate` (Windows)
4. Install dependencies: `pip install -r requirements.txt`
5. Run: `python src/main.py`

## Usage
Access the chatbot at http://127.0.0.1:7860 and enter requests like "Book 2 tickets for Avatar tomorrow at 8 PM".
